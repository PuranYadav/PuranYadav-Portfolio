- Mobile navigation and scroll progress
- Plain HTML5/CSS3/JavaScript for easy hosting

## IMPORTANT: Add your own photo
The current `assets/profile-placeholder.svg` is a professional developer illustration. To use your real photo:
1. Put your photo in `assets/profile.jpg` (or `.png`).
2. In `index.html`, change:
   `<img src="assets/profile-placeholder.svg" ...>`
   to:
   `<img src="assets/profile.jpg" alt="Puran Yadav">`

Use a clear professional headshot with a plain background.

## Add GitHub
In `index.html`, replace every:
`https://github.com/YOUR_GITHUB_USERNAME`
with your real GitHub profile URL.
